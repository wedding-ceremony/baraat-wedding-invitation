BARAAT PEARL & GOLD INVITATION — VERCEL VERSION
=================================================

This is a static website package for Vercel. No cPanel, database, PHP, or build command is needed.

DEPLOY OPTION 1 — VERCEL DASHBOARD
1. Extract this ZIP on your computer.
2. Create a new GitHub repository and upload the CONTENTS of this folder (index.html, style.css, script.js, assets/, vercel.json).
3. Sign in to Vercel and choose Add New > Project.
4. Import that GitHub repository.
5. Framework Preset: Other.
6. Build Command: leave blank.
7. Output Directory: leave blank (project root).
8. Click Deploy.
9. Vercel will provide a shareable .vercel.app URL.

DEPLOY OPTION 2 — VERCEL CLI
1. Install Node.js and Vercel CLI on your computer.
2. Open a terminal inside this extracted folder.
3. Run: vercel
4. Follow the prompts. For production deployment run: vercel --prod

MOBILE PREVIEW
After deployment, open the generated Vercel URL on iPhone Safari or Android Chrome.

INCLUDED
- index.html, style.css, script.js
- assets/pearl-gold-frame.jpg (supplied reference frame)
- vercel.json with X-Robots-Tag noindex/nofollow headers
- Touch/mouse scratch-to-reveal interaction (60% threshold)
- Date reveal, 3D invitation flip, countdown
- Google Maps, WhatsApp and Call actions
- Responsive mobile-first styling and iOS safe-area support

IMPORTANT
- This is a static frontend. It does not need a database.
- Vercel deployment creates a public URL. noindex/nofollow discourages search engines but does NOT make the link private or password-protected.
- Confirm the Google Maps venue pin before sharing the invitation.
- Background music is not included yet.
